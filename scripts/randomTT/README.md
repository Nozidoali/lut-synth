# Random TT / method-layer scripts

Application-agnostic experiments that demonstrate the narrow_and_resub
method itself — not tied to Shor's or chemistry.

| Script | What it does |
|---|---|

| `figures/fig2_narrow_lac.py` | Schematic of narrow's 5 local replacement candidates |
| `figures/fig4_random_tt_comparison.py` | AND-count comparison across HLQCS benchmarks (ResubALS / ILP / narrow) |
